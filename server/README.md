# 재입고 알림 서버 (개발판)

품절 상품에 🔔 를 걸어두면, 이 서버가 **1분마다** 재고를 확인하다가 들어오는 즉시 **텔레그램과 이메일**로 알려줍니다. Safari나 Mac이 꺼져 있어도 동작합니다(서버는 Cloudflare에서 돌아감).

- 알림을 걸면 바로 "재입고 알림 설정 완료" 메시지가 옵니다 (사이트명, 향수명, 옵션, 가격 포함)
- 재입고되면 "✅ 재입고!" 메시지와 바로 구매 링크가 옵니다
- 다시 품절되면 계속 지켜보다가 또 들어오면 다시 알려줍니다
- 6시간 넘게 확인이 안 되면(사이트 차단·페이지 변경) 한 번 알려줍니다

비용: **무료** (Cloudflare Workers·D1 무료 요금제, Resend 무료 요금제, 텔레그램 무료)

## 준비물

| 항목 | 할 일 |
|---|---|
| Node.js | [nodejs.org](https://nodejs.org) 에서 LTS 설치 (터미널에서 `node -v` 가 나오면 이미 있음) |
| 텔레그램 | 아이폰에 텔레그램 앱 설치·가입 |
| Cloudflare 계정 | [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) 무료 가입 (설치 중에 해도 됨) |
| Resend 계정 | [resend.com](https://resend.com) 무료 가입. **가입한 메일 주소로만** 알림 메일을 받을 수 있음 |

## 1. 텔레그램 봇 만들기 (2분)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력
3. 봇 이름 입력 (예: `향수 재입고 알림`)
4. 봇 아이디 입력 — `bot` 으로 끝나야 함 (예: `taekyung_scent_bot`)
5. BotFather 가 보내주는 **토큰**(`123456789:AA…` 모양)을 복사해 둠 — 설치할 때 붙여넣음
6. BotFather 메시지의 `t.me/…` 링크를 눌러 내 봇과 대화를 열고 **아무 메시지나 보냄**(예: `/start`) — 이걸 해야 서버가 나에게 메시지를 보낼 수 있음

> 토큰은 비밀번호와 같습니다. 다른 사람에게 보내지 마세요.

## 2. Resend API 키 만들기 (2분)

1. [resend.com](https://resend.com) 가입 (알림 받을 메일 주소로)
2. 왼쪽 **API Keys** → **Create API Key** → 이름 아무거나, 권한 **Sending access** → 만들기
3. `re_…` 로 시작하는 키를 복사해 둠 (한 번만 보여줌)

## 3. 서버 설치

```
cd ~/ScentFinder/server
./setup.sh
```

순서대로 진행됩니다.
1. Cloudflare 로그인 — 브라우저가 열리면 로그인(또는 가입) 후 **Allow**
2. 데이터베이스·서버 자동 생성. 처음이면 `workers.dev` 주소 이름을 물어볼 수 있음 → 원하는 이름 입력(예: `taekyung`)
3. **텔레그램 봇 토큰** 붙여넣기 (화면에 안 보이는 게 정상) → Enter
4. **Resend API 키** 붙여넣기 → Enter
5. **메일 주소** 입력 (Resend 가입 메일) → Enter
6. 마지막에 **서버 주소**와 **접속 키**가 나옴 (접속 키는 클립보드에도 복사됨)

## 4. 확장 프로그램에 연결

1. 확장 검색 화면 → **재입고 알림** 칸 열기
2. **알림 서버 주소**, **접속 키** 붙여넣기 → **저장하고 연결 확인**
3. **텔레그램 연결** → 텔레그램에 "연결됐어요" 메시지가 오면 성공
4. **테스트 알림 보내기** → 텔레그램과 메일 둘 다 오는지 확인
   - 메일이 안 보이면 스팸함 확인 (보내는 주소: `onboarding@resend.dev`)

## 5. 사용

1. 검색 후 위쪽 필터의 **품절 포함**을 켬
2. 품절 상품 카드의 **🔔 재입고 알림** 누름 → 바로 확인 메시지가 옴
3. 해제: 카드의 **🔔 알림 중 · 해제** 또는 재입고 알림 칸의 목록에서 **해제**

아이폰도 같은 서버 주소와 접속 키를 넣으면 같은 알림 목록을 씁니다.

## 동작 방식과 한도

| 항목 | 내용 |
|---|---|
| 확인 간격 | 1분 (Cloudflare 무료 요금제 최소 간격) |
| 알림 속도 | 재입고 후 보통 1~2분 안. 쇼핑몰 쪽 캐시 때문에 조금 늦을 수 있음 |
| 동시에 확인하는 상품 | 1분에 25개. 더 많으면 돌아가며 확인(예: 50개면 상품마다 2분 간격) |
| 상품 페이지를 통째로 읽는 사이트 | 1분에 8개까지 (무료 요금제 CPU 한도 때문) |
| 확인 방법 | Shopify 몰: 옵션(용량)별 재고 데이터 / WooCommerce 몰: 상품 재고 데이터 / 그 외: 상품 페이지의 구조화 데이터 |
| 안 되는 사이트 | 봇 차단이 강한 곳(서버 접속을 막음). 알림을 걸 때 서버가 먼저 확인해서, 안 되면 "봇 차단 때문에 확인할 수 없어요"라고 알려줌 |
| 옵션 구분 | 페이지에 용량별 재고가 없는 사이트는 "어떤 용량이든 입고되면" 기준 (메시지에 표시) |

## 업데이트

`git pull` 로 서버 코드가 바뀌었으면:

```
cd ~/ScentFinder/server
npx wrangler deploy
```

## 문제 해결

| 증상 | 해결 |
|---|---|
| 확장에서 "알림 서버에 연결할 수 없어요" | 서버 주소 오타 확인. 브라우저로 서버 주소를 열었을 때 `{"ok":true,…}` 가 나와야 함 |
| "접속 키가 맞지 않아요" | `server/.alerts-key` 파일 내용이 접속 키. `cat ~/ScentFinder/server/.alerts-key` |
| "텔레그램에서 내 봇에게 아무 메시지나…" | 내 봇과의 대화에서 `/start` 보낸 뒤 다시 **텔레그램 연결** |
| 메일만 안 옴 | 스팸함 확인. 메일 주소가 Resend 가입 주소와 같은지 확인 → 다르면 `./setup.sh` 다시 실행해 메일 주소만 입력 |
| 값을 바꾸고 싶음 | `./setup.sh` 다시 실행. 바꾸지 않을 항목은 비워 두고 Enter |
| 서버 기록 보기 | `npx wrangler tail` (실시간 로그) |

## 지우기

```
cd ~/ScentFinder/server
npx wrangler delete
npx wrangler d1 delete scentfinder-alerts
```
