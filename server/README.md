# 재입고 알림 (개발판)

품절 상품에 🔔 를 걸어두면 서버가 **1분마다** 재고를 확인하다가, 들어오는 즉시 **텔레그램이나 이메일**로 알려줍니다. Safari나 Mac이 꺼져 있어도 동작합니다(서버는 Cloudflare에서 돌아감).

역할은 둘로 나뉩니다.

| | 하는 일 | 횟수 |
|---|---|---|
| **운영자** (서버 주인) | 서버 설치, 텔레그램 봇·메일 발송 키 등록 (`setup.sh`) | 한 번 |
| **사용자** (확장 쓰는 사람 누구나) | 확장 화면에서 텔레그램 연결 / 이메일 인증 → 🔔 | 각자 |

사용자는 터미널·설정 파일을 만질 필요가 없습니다.

---

## 사용자: 알림 받기

1. 확장 검색 화면 → **재입고 알림** 칸 열기
2. 알림 받을 곳 연결 (둘 중 하나 이상)
   - **텔레그램**: **텔레그램 연결** → 텔레그램 앱이 열리면 **시작** → 확장에 "✓ 연결됨" 표시
   - **이메일**: 메일 주소 입력 → **인증 메일 보내기** → 받은 메일의 **메일 주소 인증하기** 클릭 → 확장에서 **인증했어요**
3. **테스트 알림 보내기**로 확인
4. 검색 후 필터의 **품절 포함**을 켜고, 품절 상품의 **🔔 재입고 알림** → 바로 "재입고 알림 설정 완료" 메시지(사이트명·향수명·옵션·가격)가 옴
5. 해제: 카드의 **🔔 알림 중 · 해제**, 또는 재입고 알림 칸의 목록에서 **해제**

- 재입고되면 "✅ 재입고!" 메시지와 바로 구매 링크가 옵니다. 다시 품절됐다가 또 들어오면 또 알려줍니다.
- 6시간 넘게 확인이 안 되면(사이트 차단·페이지 변경) 한 번 알려줍니다.
- **아이폰과 Mac에서 같은 목록을 쓰려면**: 재입고 알림 → 고급 → 한쪽의 **기기 연결 코드**를 복사해 다른 기기에 넣기
- **연결 끊기**: 텔레그램은 봇에게 `/stop` 또는 확장의 **연결 해제**. 메일은 알림 메일 아래 **메일 알림 끄기** 또는 확장의 **해제**
- **내 정보 지우기**: 재입고 알림 → 고급 → **내 알림 정보 모두 삭제**

> 이메일은 운영자가 도메인을 등록하기 전까지 **일부 주소만** 됩니다(아래 "도메인 등록" 참고). 그동안은 텔레그램을 쓰세요.

## 운영자: 서버 설치 (한 번, 약 10분)

### 준비물

| 항목 | 할 일 |
|---|---|
| Node.js | [nodejs.org](https://nodejs.org) LTS (터미널에서 `node -v` 가 나오면 이미 있음) |
| 텔레그램 | 앱 설치·가입 |
| Cloudflare 계정 | [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) 무료 가입 (설치 중에 해도 됨) |
| Resend 계정 | [resend.com](https://resend.com) 무료 가입 |

### 1. 텔레그램 봇 만들기 (2분)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` → 봇 이름(예: `향수 재입고 알림`) → 봇 아이디(`bot` 으로 끝나야 함, 예: `scent_restock_bot`)
3. BotFather 가 보내주는 **토큰**(`123456789:AA…`)을 복사해 둠

> 토큰은 비밀번호와 같습니다. 다른 사람에게 보내지 마세요. 사용자 연결(웹훅)은 서버가 알아서 설정합니다.

### 2. Resend API 키 만들기 (2분)

1. [resend.com](https://resend.com) 가입
2. **API Keys** → **Create API Key** → 권한 **Sending access** → `re_…` 키 복사 (한 번만 보여줌)

### 3. 설치

```
cd ~/ScentFinder/server
./setup.sh
```

1. Cloudflare 로그인 — 브라우저가 열리면 로그인(또는 가입) 후 **Allow**
2. 데이터베이스·서버 자동 생성. 처음이면 `workers.dev` 주소 이름을 물어볼 수 있음 → 원하는 이름 입력
3. **텔레그램 봇 토큰** 붙여넣기 (화면에 안 보이는 게 정상) → Enter
4. **Resend API 키** 붙여넣기 → Enter
5. 서버 주소가 확장 설정(`extension/alerts-config.js`)에 자동으로 기록됨

### 4. 확장 다시 빌드

Xcode 에서 ▶ → Safari ⌘Q 후 다시 열기 → 위 "사용자: 알림 받기"대로 연결해서 테스트.

### 도메인 등록 (나중에, 이메일을 모든 사용자에게 열 때)

Resend 는 도메인 인증 전에는 **Resend 가입 메일로만** 보낼 수 있습니다. 모든 사용자가 메일 알림을 받으려면:

1. 도메인 구입 (아무 등록업체)
2. Resend → **Domains** → **Add Domain** → 안내되는 DNS 레코드를 도메인 관리 화면에 추가 → **Verified** 될 때까지 대기
3. 보내는 주소 등록:
   ```
   cd ~/ScentFinder/server
   ./setup.sh --email-from
   ```
   예: `향수 최저가 <alert@내도메인.com>`

서버를 다시 올릴 필요 없이 바로 적용됩니다.

## 동작 방식과 한도 (무료 요금제 기준)

| 항목 | 내용 |
|---|---|
| 확인 간격 | 1분 (Cloudflare 무료 요금제 최소 간격) |
| 알림 속도 | 재입고 후 보통 1~2분 안. 쇼핑몰 쪽 캐시 때문에 조금 늦을 수 있음 |
| 1분에 확인하는 상품 | **서비스 전체** 25개 주소. 같은 상품을 여러 명이 걸어도 한 번만 확인. 더 많으면 돌아가며 확인 (예: 50개면 상품마다 2분 간격) |
| 상품 페이지를 통째로 읽는 사이트 | 1분에 8개까지 (CPU 한도) |
| 사용자당 알림 | 30개 (`wrangler.toml` 의 `MAX_PER_USER`) |
| 확인 방법 | Shopify 몰: 옵션(용량)별 재고 / WooCommerce 몰: 상품 재고 / 그 외: 상품 페이지의 구조화 데이터 |
| 안 되는 사이트 | 봇 차단이 강한 곳. 알림을 걸 때 서버가 먼저 확인해서, 안 되면 바로 알려줌 |
| 이메일 | Resend 무료: 월 3,000통, 하루 100통 |
| 스팸 방지 | 메일은 인증된 주소로만 발송, 인증 메일은 1분에 1번·하루 5번, 가입은 IP 당 시간당 20번 |

사용자가 많아져 1분 확인이 밀리면 Workers 유료 요금제(월 $5)로 올리고 `src/index.js` 위쪽의 한도 값을 늘리면 됩니다.

## 서버에 저장되는 정보

- 사용자: 기기별 무작위 ID, 접속 키의 해시(원래 키는 저장 안 함), 연결한 텔레그램 대화 ID·이름, 인증한 메일 주소, 언어
- 알림: 상품 주소, 사이트명, 상품명, 옵션, 가격, 확인 기록
- 사용자가 **내 알림 정보 모두 삭제**를 누르면 전부 지워짐

## 업데이트

`git pull` 로 서버 코드가 바뀌었으면:

```
cd ~/ScentFinder/server
npx wrangler d1 execute scentfinder-alerts --remote --file schema.sql --yes
npx wrangler deploy
```

## 문제 해결

| 증상 | 해결 |
|---|---|
| 재입고 알림 칸에 "준비 중" | `extension/alerts-config.js` 에 서버 주소가 없음 → `./setup.sh` 다시 실행 후 Xcode ▶ |
| "알림 서버에 연결할 수 없어요" | 브라우저로 서버 주소를 열었을 때 `{"ok":true,…}` 가 나오는지 확인 |
| 텔레그램에서 "시작"을 눌렀는데 연결 안 됨 | 15분 안에 눌러야 함. 확장에서 **텔레그램 연결**을 다시 누르기. 계속 안 되면 `npx wrangler tail` 로 기록 확인 |
| "텔레그램 봇 설정에 문제가 있어요" | 봇 토큰이 틀림 → `./setup.sh` 다시 실행해서 토큰만 다시 입력 |
| 인증 메일이 안 옴 | 스팸함 확인. 도메인 등록 전이면 Resend 가입 메일만 됨 |
| 서버 기록 보기 | `npx wrangler tail` (실시간 로그) |

## 지우기

```
cd ~/ScentFinder/server
npx wrangler delete
npx wrangler d1 delete scentfinder-alerts
```

## 파일

| 파일 | 역할 |
|---|---|
| `src/index.js` | 서버 코드 (가입, 텔레그램 연결, 메일 인증, 1분마다 재고 확인, 알림 발송) |
| `schema.sql` | 데이터베이스 표 |
| `wrangler.toml` | Cloudflare 설정 (1분 예약, 사용자당 알림 수) |
| `setup.sh` | 운영자 설치 스크립트 |
| `test/run.mjs` | 테스트 (`node test/run.mjs`, 가짜 쇼핑몰·텔레그램·메일) |
| `../extension/alerts-config.js` | 확장에 들어가는 서버 주소 (setup.sh 가 채움) |
