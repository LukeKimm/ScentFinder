# 향수 최저가 — Xcode 설치 & 앱스토어 출시 가이드

Oct 20, 2026 · @Taekyung Kim

## 개요

내 Mac과 아이폰에만 쓰려면 Part 1(무료, 약 30분)만 하면 되고, 다른 사람도 앱스토어에서 받게 하려면 Part 2(연 $99, 심사 포함 1\~2주)까지 진행합니다.

| 구분 | Part 1 개인 설치 | Part 2 앱스토어 출시 |
| --- | --- | --- |
| 비용 | 무료 (Apple ID만) | Apple Developer Program 연 $99 |
| 쓸 수 있는 사람 | 본인 기기만 | 누구나 App Store에서 설치 |
| 유지 | 아이폰은 7일마다 Xcode로 재설치 | 갱신 불필요, 업데이트는 심사 후 배포 |
| 필요한 것 | Mac, Xcode, 케이블 | Part 1 + 개인정보처리방침 URL, 스크린샷, 설명문 |

먼저 Part 1로 직접 써보면서 사이트가 잘 잡히는지 확인한 다음, 만족스러우면 Part 2로 넘어가는 순서를 권합니다.

## Part 1. Xcode로 내 기기에 설치

### 1-1. 준비

파일을 Mac으로 옮기고, Xcode에 Apple ID를 등록해 두면 준비가 끝납니다.

1. **파일 옮기기**: ScentFinder.zip을 Mac으로 가져옵니다. Mac에서 claude.ai에 접속해 받거나, 아이폰에서 받은 뒤 AirDrop으로 보냅니다.
2. **압축 풀기**: 압축을 풀어 `ScentFinder` 폴더를 **문서** 폴더로 옮깁니다. 경로가 `~/Documents/ScentFinder`가 되게 합니다.
3. **Xcode 첫 실행**: Xcode를 열고 추가 구성요소 설치가 뜨면 끝까지 진행합니다.
4. **iOS 플랫폼 확인**: Xcode › Settings › **Components**에서 iOS가 설치돼 있는지 봅니다. 없으면 **Get**을 눌러 받습니다(수 GB, 시간이 걸려요).
5. **Apple ID 등록**: Xcode › Settings › **Accounts** › 왼쪽 아래 **+** › Apple ID로 로그인합니다. 무료 계정이면 "이름 (Personal Team)"이 생깁니다.

### 1-2. Xcode 프로젝트 만들기

`build.sh`가 Apple의 변환 도구로 Mac용·iOS용 앱과 확장을 한 번에 만듭니다.

1. Spotlight(⌘ Space)에서 **터미널**을 엽니다.
2. 아래 세 줄을 한 줄씩 붙여넣고 엔터를 누릅니다.

```
cd ~/Documents/ScentFinder
chmod +x build.sh
./build.sh
```

3. "✅ 프로젝트 생성 완료"가 뜨면 Xcode가 자동으로 열립니다. 프로젝트는 `ScentFinder/xcode/ScentFinder` 안에 생깁니다.
4. "확인되지 않은 개발자" 경고로 막히면 시스템 설정 › 개인정보 보호 및 보안 맨 아래 **그래도 열기**를 누르고 다시 실행합니다.

번들 ID는 기본으로 `com.(Mac 사용자 이름).scentfinder`가 됩니다. 앱스토어에 올릴 계획이면 지금 원하는 ID로 정해두는 게 좋습니다. 예: `./build.sh com.taekyung.scentfinder`

### 1-3. 서명 설정

4개 타깃 모두에 같은 Team을 지정해야 실행됩니다. 하나라도 빠지면 빌드가 실패합니다.

1. Xcode 왼쪽 파일 목록 맨 위 **파란 ScentFinder 아이콘**을 클릭합니다.
2. 가운데 왼쪽 **TARGETS**에서 4개를 확인합니다.
   - ScentFinder (iOS)
   - ScentFinder Extension (iOS)
   - ScentFinder (macOS)
   - ScentFinder Extension (macOS)
3. 첫 번째 타깃 선택 › 위쪽 **Signing & Capabilities** 탭으로 갑니다.
4. **Automatically manage signing** 체크를 확인하고 **Team**에서 "본인 이름 (Personal Team)"을 고릅니다.
5. 나머지 3개도 똑같이 합니다.

| 오류 문구 | 원인 | 해결 |
| --- | --- | --- |
| Failed to register bundle identifier | 다른 사람이 이미 쓰는 번들 ID | `xcode` 폴더 삭제 › `./build.sh com.다른이름.scentfinder` 재실행 › 서명 다시 설정 |
| No devices / Communication with Apple failed | iOS 타깃인데 아이폰 미연결 | 1-5에서 아이폰을 연결하면 사라짐. Mac 설치만 할 땐 무시 |
| Signing for "…" requires a development team | 해당 타깃에 Team 미지정 | 그 타깃을 선택해 Team 지정 |

### 1-4. Mac Safari에 설치

실행 대상을 My Mac으로 두고 ▶를 누른 뒤, Safari 설정에서 확장을 켜고 웹사이트 권한을 허용하면 끝입니다.

1. Xcode 창 맨 위 가운데 실행 대상을 **ScentFinder (macOS)** › **My Mac**으로 바꿉니다.
2. 왼쪽 위 **▶**(⌘R)를 누릅니다. 빌드가 끝나면 작은 앱 창이 뜹니다.
3. 창의 버튼을 누르거나 Safari › 설정 › **확장 프로그램** 탭으로 갑니다.
4. 목록에서 **향수 최저가**를 체크합니다.
5. 오른쪽 **웹사이트 편집** › **다른 웹사이트**를 **허용**으로 바꿉니다. 이걸 안 하면 다른 사이트 가격을 읽지 못합니다.
6. Safari 툴바의 갈색 향수병 아이콘을 누르면 검색 팝업이 뜹니다.

확장 목록에 안 보이면 서명되지 않은 확장을 허용해야 합니다.

1. Safari › 설정 › 고급 › **웹 개발자용 기능 보기** 체크
2. 설정에 새로 생긴 **개발자** 탭 › **서명되지 않은 확장 프로그램 허용** 체크
3. 이 체크는 Safari를 완전히 끄면 풀릴 수 있습니다. 아이콘이 사라지면 다시 체크합니다.

### 1-5. 아이폰 Safari에 설치

아이폰은 개발자 모드를 켜고, 설치 후 내 Apple ID를 신뢰해야 열립니다.

1. 아이폰을 케이블로 Mac에 연결하고, 아이폰의 "이 컴퓨터를 신뢰하겠습니까?"에서 **신뢰** › 암호 입력.
2. 아이폰 설정 › 개인정보 보호 및 보안 › 맨 아래 **개발자 모드** 켜기 › 재시동 후 **켜기** 한 번 더. 메뉴가 안 보이면 Xcode에 한 번 연결한 뒤 다시 봅니다.
3. Xcode 실행 대상을 **ScentFinder (iOS)** › 내 아이폰으로 바꿉니다. 처음엔 "Preparing device"가 몇 분 걸릴 수 있습니다.
4. **▶** 실행. 앱이 설치되지만 처음엔 "신뢰할 수 없는 개발자"로 안 열립니다.
5. 아이폰 설정 › 일반 › **VPN 및 기기 관리** › 본인 Apple ID › **신뢰**.
6. 설정 › 앱 › **Safari** › **확장 프로그램** › **향수 최저가** 켜기 › **기타 웹사이트**를 **허용**.
7. Safari 주소창 왼쪽 메뉴 아이콘 › 확장 프로그램 › 향수 최저가를 누르면 검색 팝업이 뜹니다.

### 1-6. 7일 재설치와 코드 수정

- **7일마다(무료 계정)**: 서명이 만료되면 확장이 안 열립니다. 아이폰을 연결하고 Xcode에서 iOS 대상으로 ▶만 다시 누르면 되고, 설정은 유지됩니다. Mac은 보통 그대로 쓸 수 있습니다.
- **기존 파일을 고쳤을 때**: Xcode에서 ▶를 다시 누르면 반영됩니다.
- **새 파일이 추가된 버전을 받았을 때**: `xcode` 폴더를 지우고(`rm -rf xcode`) `./build.sh`를 다시 실행한 뒤 1-3 서명을 다시 합니다.

## Part 2. 앱스토어에 출시

### 2-1. 출시 전 준비

개발자 프로그램 가입, 개인정보처리방침 페이지, 심사 기준에 맞춘 권한 축소 세 가지가 먼저 필요합니다.

**① Apple Developer Program 가입**

1. [developer.apple.com/programs/enroll](https://developer.apple.com/programs/enroll/)에서 개인(Individual)으로 가입합니다. 연회비는 99 USD이고 결제 화면엔 원화로 표시됩니다.
2. Apple ID에 **이중 인증**이 켜져 있어야 합니다.
3. 이름은 반드시 **법적 실명**으로 입력합니다. 별명이나 회사명을 쓰면 승인이 늦어지고, 이 이름이 App Store 판매자명으로 표시됩니다.
4. 이메일·전화·주소 확인 후 약관 동의와 결제를 마치면 승인 메일이 옵니다.
5. 가입이 끝나면 Xcode › Settings › Accounts에서 팀이 "Personal Team" 대신 본인 이름(유료 팀)으로 바뀐 걸 확인합니다.

**② 개인정보처리방침 URL**

App Store Connect는 모든 앱에 개인정보처리방침 URL을 요구합니다. 이 확장은 서버로 데이터를 보내지 않으니 짧은 페이지면 충분합니다. 노션 공개 페이지나 네이버 블로그 글 하나로도 됩니다.

- 넣을 내용: 수집하는 개인정보 없음, 검색어·설정은 기기 안에만 저장, 검색 시 각 쇼핑몰과 환율 API(open.er-api.com)에 직접 요청, 문의 이메일

**③ 심사 리스크 점검**

| 심사 기준 | 이 확장에서 걸리는 점 | 대응 |
| --- | --- | --- |
| 4.4.2 Safari 확장은 필요한 사이트에만 접근 권한 요청 | 지금은 `<all_urls>`(모든 사이트) 권한 | 출시용은 등록된 쇼핑몰 도메인만 요청하고, 사용자 추가 사이트는 추가할 때 권한을 묻도록 변경 |
| 4.4 확장을 담은 앱엔 도움말·설정 화면 권장 | 설치용 앱이 Xcode 기본 템플릿 | 사용법 안내 화면으로 교체 (2-2) |
| 5.2.2 제3자 서비스 콘텐츠는 이용약관상 허용돼야 함 | 쇼핑몰 가격을 읽어옴 | 상품명·가격·링크만 표시하고 구매는 원 사이트로 연결. 비슷한 앱(ScentSift)이 이미 App Store에 있음 |

③의 권한 축소와 설치용 앱 화면 교체는 코드 수정이 필요합니다. 출시를 결정하면 출시용 버전으로 바꿔드릴게요.

### 2-2. 앱 정보 다듬기

출시 후엔 번들 ID를 바꿀 수 없으니, 업로드 전에 아래 항목을 확정합니다.

| 항목 | 정할 것 | 어디서 |
| --- | --- | --- |
| 번들 ID | 예: `com.taekyung.scentfinder`. 한 번 정하면 변경 불가 | `./build.sh com.taekyung.scentfinder` 로 생성 |
| 앱 이름 | App Store에 보일 이름(30자 이내), 다른 앱과 중복 불가. 예: 향수 최저가 - 해외 향수 가격비교 | App Store Connect (2-3) |
| 홈 화면 이름 | 아이콘 아래 짧은 이름 | 각 앱 타깃 › General › **Display Name** |
| 버전 / 빌드 | 버전 1.1.0, 빌드 1. 다시 올릴 때마다 빌드 번호 +1 | 각 타깃 › General › Version / Build |
| 카테고리 | 쇼핑 또는 유틸리티 | App Store Connect |
| 아이콘 | 1024×1024 PNG, 투명 배경 불가 | 변환 도구가 `icon-512.png`로 채움. 출시용은 1024 원본으로 교체 |
| 설치용 앱 화면 | 기본 영어 템플릿 → 사용법 안내(한/영) | 출시용 버전에서 교체 |
| 접근 권한 | `<all_urls>` → 쇼핑몰 도메인 목록 | 출시용 버전에서 교체 |

번들 ID를 iOS와 macOS가 같이 쓰면 Universal Purchase로 묶여, 한 번 받으면 아이폰과 Mac에서 모두 쓸 수 있습니다. 변환 도구 기본값이 이 방식입니다.

### 2-3. App Store Connect에 앱 등록

[appstoreconnect.apple.com](https://appstoreconnect.apple.com)에서 앱 기록을 만들고 상품 페이지 정보를 채웁니다.

1. **앱** › 왼쪽 위 **+** › **신규 앱**.
2. 플랫폼 **iOS**와 **macOS**를 모두 체크, 이름·기본 언어(한국어)·번들 ID(드롭다운에서 선택)·SKU(아무 고유값, 예: scentfinder001)를 입력합니다. 번들 ID가 목록에 없으면 Xcode에서 유료 팀으로 한 번 빌드하면 자동 등록됩니다.
3. **앱 정보**: 카테고리(쇼핑), 연령 등급 설문(모두 "없음"), 개인정보처리방침 URL.
4. **가격 및 사용 가능 여부**: 무료, 판매 국가 선택.
5. **앱 개인정보 보호** › 시작하기 › **"아니요, 이 앱에서 데이터를 수집하지 않습니다"** › 저장 › 게시. 검색어와 설정이 기기 안에만 저장되므로 이 선택이 맞습니다.
6. 버전 페이지(iOS, macOS 각각)에 스크린샷·설명·키워드·지원 URL을 넣습니다.

**스크린샷 규격** (PNG/JPG, 투명도 없음, 기기당 1\~10장)

| 기기 | 필수 크기 (px) | 찍는 법 |
| --- | --- | --- |
| iPhone (Dynamic Island, 중간 화면) | 1179×2556 또는 1206×2622 세로 | 해당 크기 아이폰에서 측면 버튼+볼륨 업. 다른 기기면 Xcode 시뮬레이터(iPhone 16/17 계열)에서 ⌘S |
| Mac | 1280×800, 1440×900, 2560×1600, 2880×1800 중 하나 (16:10) | 검색 결과 화면을 띄우고 ⇧⌘4, 크기 맞춰 자르기 |

추천 장면: ① 검색 결과와 최저가 카드 ② 종류 필터·용량 선택 ③ 사이트 선택 패널 ④ 영어 화면.

**설명문에 꼭 넣을 것** (심사 기준 4.4)

- Safari 확장이라는 점과 켜는 방법(설정 › Safari › 확장 프로그램)
- 확장이 하는 일: 해외 향수 쇼핑몰 가격 비교, 원화 환산
- 가격은 상품가 기준이며 배송비·관부가세 미포함

출처: [스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications), [앱 개인정보 관리](https://developer.apple.com/help/app-store-connect/manage-app-information/manage-app-privacy)

### 2-4. Archive 업로드와 심사 제출

Xcode에서 iOS와 macOS를 각각 Archive해 올리고, App Store Connect에서 빌드를 골라 심사에 제출합니다.

1. **팀 변경**: 4개 타깃의 Team을 유료 개발자 팀으로 바꿉니다(1-3과 같은 위치).
2. **iOS Archive**: 실행 대상을 **ScentFinder (iOS)** › **Any iOS Device (arm64)** 로 바꾸고 메뉴 **Product › Archive**.
3. 끝나면 Organizer 창이 뜹니다. 방금 만든 아카이브 선택 › **Distribute App** › **App Store Connect** › **Upload** › 기본값 그대로 진행.
4. **macOS Archive**: 실행 대상을 **ScentFinder (macOS)** › **Any Mac** 으로 바꾸고 2\~3을 반복합니다.
5. 10\~30분 뒤 App Store Connect › 앱 › **TestFlight** 탭에 빌드가 나타납니다. "수출 규정 준수" 질문이 뜨면 HTTPS만 쓰므로 **면제 대상 암호화만 사용**(표준 암호화 외 없음)을 고릅니다.
6. **TestFlight로 먼저 테스트(권장)**: 내부 테스터에 본인을 추가하면 아이폰 TestFlight 앱에서 설치됩니다. 7일 재설치 없이 90일간 쓸 수 있고, 여자친구 등 지인도 초대할 수 있습니다.
7. **심사 제출**: iOS 버전 페이지 › **빌드** 섹션에서 업로드한 빌드 선택 › 심사 정보(연락처, "로그인 불필요", 메모에 확장 켜는 방법) › **심사에 추가** › **심사에 제출**. macOS 버전도 같은 방식으로 제출합니다.
8. 결과는 이메일로 옵니다. 승인되면 자동 또는 수동으로 출시됩니다. 거절되면 해결 센터 메시지에 이유가 적혀 있으니 그 내용으로 고쳐 다시 제출합니다.

## 부록. 체크리스트와 문제 해결

**개인 설치 체크리스트**

- [ ] Xcode에 Apple ID 등록, iOS 플랫폼 설치
- [ ] `./build.sh` 실행
- [ ] 4개 타깃 Team 지정
- [ ] Mac: 확장 켜기 + 다른 웹사이트 허용
- [ ] 아이폰: 개발자 모드, 개발자 앱 신뢰, 확장 켜기 + 기타 웹사이트 허용

**출시 체크리스트**

- [ ] Apple Developer Program 가입 (실명, 이중 인증)
- [ ] 개인정보처리방침 페이지 게시
- [ ] 출시용 버전 적용 (사이트 권한 축소, 설치용 앱 안내 화면, 1024 아이콘)
- [ ] 번들 ID 확정 후 프로젝트 재생성
- [ ] App Store Connect 신규 앱 (iOS + macOS)
- [ ] 앱 개인정보: 데이터 수집 안 함
- [ ] 스크린샷 iPhone 1장 이상, Mac 1장 이상
- [ ] iOS·macOS Archive 업로드, TestFlight 확인
- [ ] 심사 제출

**자주 막히는 곳**

| 증상 | 해결 |
| --- | --- |
| 확장은 켜졌는데 모든 사이트가 "실패" | 웹사이트 권한이 "묻기"나 "거부"로 돼 있음. 다른/기타 웹사이트를 허용으로 |
| 아이폰에서 앱 아이콘을 누르면 바로 꺼짐 | 7일 서명 만료. Xcode에서 iOS로 다시 실행 |
| Mac Safari 확장 목록에서 사라짐 | 개발자 탭의 "서명되지 않은 확장 허용" 다시 체크 |
| Archive 메뉴가 회색 | 실행 대상이 시뮬레이터로 돼 있음. Any iOS Device / Any Mac으로 |
| 업로드 후 빌드가 안 보임 | 10\~30분 대기. 이메일로 처리 오류가 왔는지 확인 |
| 심사 거절: 4.4.2 권한 과다 | 출시용 버전(쇼핑몰 도메인만 요청)으로 교체 후 재제출 |
